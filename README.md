# go-net-catcher: Сетевой перехватчик на Go
## Обзор
Простой сетевой перехватчик на Go. Может:
* Перехватывать TCP пакеты
* Перехватывать IP пакеты

Настройка через ```configs.yaml```

## Сборка
Выполните команду:
```
go build -o catcher.exe .
```

## Запуск
Для работы нужно установить Npcap(Windows)/libpcap(Linux/MacOS)
